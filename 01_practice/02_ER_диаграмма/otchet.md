# Задание 02: ER-диаграмма

## Цель
Построить ER-диаграмму для предметной области «Автосалон» в нотации Crow's Foot.

## Сущности и атрибуты
- **Марка** — id (PK), название, страна.
- **Автомобиль** — id (PK), VIN, год_выпуска, цвет, цена, id_марки (FK).
- **Клиент** — id (PK), ФИО, телефон, email, адрес.
- **Сотрудник** — id (PK), ФИО, должность, телефон.
- **Продажа** — id (PK), дата, сумма, id_автомобиля (FK), id_клиента (FK), id_сотрудника (FK).

## Связи
| Связь | Тип |
|-------|-----|
| Марка — Автомобиль | 1:N |
| Автомобиль — Продажа | 1:N |
| Клиент — Продажа | 1:N |
| Сотрудник — Продажа | 1:N |

## Описание связи «Клиент — Продажа»
Один клиент может совершить ноль, одну или несколько покупок. Каждая продажа оформляется ровно на одного клиента. Тип связи — 1:N, FK `id_клиента` находится в таблице «Продажа».

## Разбиение M:N
M:N между Клиентом и Автомобилем (тест-драйвы) разбита через промежуточную сущность **Тест-драйв** (id, id_клиента FK, id_автомобиля FK, дата, оценка). Получаем две связи 1:N.

## NULL-атрибуты
| Сущность | NOT NULL | Может быть NULL |
|----------|----------|-----------------|
| Марка | id, название | страна |
| Автомобиль | id, VIN, id_марки | год_выпуска, цвет, цена |
| Клиент | id, ФИО, телефон | email, адрес |
| Сотрудник | id, ФИО, должность | телефон |
| Продажа | id, дата, id_автомобиля, id_клиента, id_сотрудника | сумма |
